November 24, 2026 Weekly Update 02

Leaderboards, search, and mobile upgrades

This update makes the arcade easier to browse, improves phone controls, and gives every playable game a place to save scores on the device.

  • Homepage leaderboard: use the new LEADERBOARD button, select a game, and view its top 10 saved scores.
  • Correct score rules: each leaderboard says whether the highest or lowest score wins, including special rules for Slide Nine and Tic Tac 67.
  • Game search: search the launcher instantly by game name, type, description, or control tag.
  • Mobile multitouch: supported games can move and aim at the same time, with joysticks for directional controls and cat buttons for one-key games.
  • Shared game bar: Home, Controls, Reload, Scores, and FPS information stay easy to reach.
  • Balance Beam made easier: the challenge is now 20 seconds with less random drift, stronger controls, gentler recovery, and a wider safe edge.
  • Arcade download refreshed: the offline file version contains the same homepage and gameplay updates.
October 25, 2026 Weekly Update 01

The arcade keeps growing

This week focuses on a clearer launcher, more useful game controls, and polish across the main games and minigames.

  • Patch Notes added: this new page will track the arcade's weekly updates.
  • Expanded minigame shelf: the launcher now includes 30 clearly labeled minigames with varied challenges.
  • Better game navigation: shared top bars keep Home, Reload, custom controls, and FPS information within reach.
  • Mobile control polish: movement games use joysticks while tap-only games keep controls that match their gameplay.
  • Minefield Mini hints: players can reveal up to three safe tiles when they get stuck.
  • Rivals HUD cleanup: hiding the HUD now also hides the loadout picker and training options for a clearer view of the arena.
